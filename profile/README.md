### Contributing to Public Projects

We welcome external contributions across our open-source tools and libraries:

1. **Browse Repositories:** Check our public pinned repositories.
2. **Find an Issue:** Look for `good-first-issue` or `help-wanted` tags.
3. **Follow Guidelines:** Read the `CONTRIBUTING.md` file in the target repository before opening a pull request.
4. **Code Quality:** Ensure all tests pass, linting checks succeed, and typing constraints are met.
